# Sorteador de Números

Aplicação web simples que sorteia números aleatórios dentro de um intervalo definido por você.

## Funcionalidades

- Escolha do intervalo (valor inicial e final)
- Escolha da quantidade de números a sortear
- Validação das entradas, com mensagem de erro quando algo está incorreto
- Exibição do resultado na tela

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

1. Clone o repositório:
```bash
   git clone https://github.com/marlongabrito/sorteador-de-numeros.git
```
2. Abra o arquivo `index.html` no navegador.
3. Preencha os campos **Do número**, **Até o número** e **Quantidade de números**.
4. Clique em **Sortear** para ver o resultado.

## Exemplo

| Do número | Até o número | Quantidade |  Resultado possível   |
|-----------|--------------|------------|-----------------------|
| 1         | 60           | 6          | 7, 23, 31, 42, 48, 59 |
